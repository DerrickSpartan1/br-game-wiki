# LMGs

One category: light machine guns, squad automatic weapons, and general-purpose machine guns that one player can carry, in rough order of when each came out. Heavy machine guns that only work mounted go to special weapons. Only one LMG family spawns per match (see the [weapon pool](../../systems/weapon-pool.md)).
