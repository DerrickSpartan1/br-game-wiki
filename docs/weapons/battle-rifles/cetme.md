## Real-world notes

4.49 kg; 1,016 mm long; 450 mm barrel; about 786 m/s; stamped steel; the fluted chamber helps extraction and leaves its signature marks on every spent case; the Model A's rear sight folds down to form a foregrip; the Model B has an integrated bipod and a perforated steel handguard, the Model C a wooden fore-stock; the 7.62×51mm CETME round is the same size as NATO's, with a lighter bullet and less powder

## In-game traits

One roster entry that rolls one of 5 versions (see [Versions](#versions) below). The Model A keeps its split bolt: the open-bolt delay applies on auto only (see [Rules](../../rules.md#open-bolt-delay)). Versions keep their real fire modes, so the civilian version rolls semi-auto only.

## Attachments

AR/LMG/battle rifle family attachments; adapter scope mount. Unique: the Model B's integrated bipod. Mag tiers (best guess, review later): 20 standard; higher tiers TBD

## Versions

5 versions after merging. The Model B and Model C differ only in small details, and Spain converted every B to NATO ammo by 1971, so they merge. The light-load 7.62×51mm CETME round is the same size as NATO's, so it plays as standard 7.62×51mm in-game, the same way the [Glisenti](../pistols/glisenti-1910.md) plays as standard 9×19. The 5.56mm Model L went on the [guns to add later](../../planning/add-later.md) list.
