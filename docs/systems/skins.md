# Skins and mastery

Skins are modular and grounded.

- **Modular:** the main gun, the silencer, and other parts each take their own skin.
- **Grounded:** skins should feel realistic; nothing super crazy.

## Wardrobe

Players set skins in a wardrobe menu, one skin per gun per part. In a match, items take on those skins as they're picked up and put on a gun.

- Each gun has its own part skins, so an FN SCAR 5.56 and an M4 5.56 are skinned separately.
- An attachment uses the skin set for the gun it's mounted on. A silencer moved from the SCAR to the M4 switches to the M4's silencer skin.

The same wardrobe setup covers gear: armor, helmets, backpacks, and similar items each get their own skins.

The player character has its own wardrobe slots too, like PUBG's, and more can be added over time:

| Slot | Removable in a match |
| --- | --- |
| Hat | Yes |
| Glasses | Yes |
| Mask | Yes |
| Neck | Yes |
| Over shirt or jacket | Yes |
| Undershirt | Yes |
| Gloves | Yes |
| Pants or legs | Yes |
| Socks | Yes |
| Shoes | Yes |
| Elbow and knee pads | No |
| Underwear, male or female | No |

- **In a match:** players arrive wearing their outfit and nothing else, and can take clothes off like in PUBG. The pads and underwear always stay on.
- **No clothing loot:** clothes never drop as loot during a match; outfits are set in the wardrobe only.

## Your character

Characters look like PUBG's and games in its style: grounded, realistic people. They're low poly while the game is tested, and the final ones look closer to PUBG's ([Art style](../planning/art-and-sound.md#art-style-low-poly-for-testing)). Customizing them works more like The Finals.

- **Body:** male or female, one body each, so everyone with that body is the same size and build. Both bodies have the same hitbox, so the choice never changes a fight (our pick).
- **Face:** one standard face per body, our own and not based on a real person ([Legal review](../planning/legal-review.md#what-to-check)).
- **Everything else is yours:** hair, eyes, and the rest are fully customizable, as much as the player wants. First list (our pick; more can be added over time):

| Part | What you pick |
| --- | --- |
| Hair | Style and color |
| Eyes | Color |
| Eyebrows | Style and color |
| Facial hair | Style and color |
| Skin | Tone |
| Face details | Freckles, scars, makeup, face paint |
| Body details | Tattoos |

- **Set in the wardrobe,** with the outfit slots above. The underwear slot follows the body.
- **In a match,** your look comes with you. Hats and helmets cover the hair under them.
- **Open:** whether colors come from a full color picker or a set of grounded colors, which options are free and which unlock, and whether players can save several characters, as The Finals allows six ([Open questions](../planning/open-questions.md#systems)).

## Melee weapons

Every player owns melee weapons and brings one into every match ([Melee](gameplay.md#melee)).

- **Picked like an outfit,** in the wardrobe.
- **Unlocked** through seasons, challenges, and mastery.
- **Looks only:** every melee weapon has the same damage, reach, and speed. Each has its own model, sounds, and animations, including an inspect, so players can be katana people, scythe people, or knife people.
- **Pans aren't owned:** they're found as loot in some matches, since they block bullets.

## Emotes

Players own emotes, like other cosmetics (owner, 2026-11-22).

- **Used from a wheel** (our pick), in the lobby and during a match, and while spectating.
- **Unlocked** through seasons, challenges, and mastery.
- **Grounded,** like the rest of the skins.

## Kill counters

A weapon skin can carry a kill counter, like Counter-Strike's StatTrak: it counts the kills made with that skin and shows the number on the gun. How it looks on each gun is TBD, like a small display or tally marks on the stock.

## Weapon mastery

Each gun family levels up through challenges, such as specific kills, unlocking cosmetics. Progress counts toward the whole family, so any version works; every C96 version counts toward C96 mastery, for example.

**Idea, not decided:** twin guns that sit in different categories could share one mastery track, even though each keeps its own roster entry. Candidates so far: the [AS Val](../weapons/assault-rifles/as-val.md) and [VSS Vintorez](../weapons/battle-rifles/vss.md), the [FN SCAR-L](../weapons/assault-rifles/scar-l.md) and [FN SCAR-H](../weapons/battle-rifles/scar-h.md), and the [HK416](../weapons/assault-rifles/hk416.md) and [HK417](../weapons/battle-rifles/hk417.md). See the [open questions](../planning/open-questions.md).
