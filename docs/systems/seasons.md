# Seasons

Season 1 is included with the base game.

Seasons have no time limits. Players choose which season to work on, like Halo, and nothing is time-gated.

- **Season pass:** new skins and unlocks; cosmetic bling.
- **New weapons:** each season adds weapons to the pool, and nobody has to unlock them to use them.
- **Challenges:** dailies are vague, like damage with ARs; bigger goals might target specific weapons.
