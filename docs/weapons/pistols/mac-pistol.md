# MAC pistol

Pistol / 3rd-slot version of the [MAC-10 / MAC-11](../smgs/mac-10-11.md).

| Spec | Detail |
| --- | --- |
| Category | Pistol / 3rd slot |
| Cartridge | Varies by version: 9×19 (main), .45 ACP, or .380 ACP |
| History | USA; civilian semi-auto MAC-10 and M-11/9 pistols (RPB, SWD, Cobray, Leinad), plus Cobray's .380 M-12 |
| Magazine (rounds) | MAC mags (ban-era PM11/9s took only 10-round mags) |
| Fire mode / rate | Semi-auto, closed bolt |

## Real-world notes

Later versions switched to a closed bolt after the ATF ruled open-bolt semi-autos too easy to convert

## In-game traits

3 versions, one per cartridge; moved to the 3rd slot like the other SMG pistols
