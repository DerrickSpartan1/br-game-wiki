# AA-12

| Spec | Detail |
| --- | --- |
| Category | Crate weapon (shotgun); the first crate weapon |
| Cartridge | 12 gauge; ammo type rolled per match, including the special crate ammo (FRAG-12 and dragon's breath) |
| History | Designed 1972 by Maxwell Atchisson; redesigned by Military Police Systems by 2005; demonstrated to the U.S. Marines but not adopted |
| Magazine (rounds) | 8 box or 20 drum (5 box on the original) |
| Fire mode / rate | Select-fire in-game (all versions); the real gun is full auto only, about 300 RPM, with short trigger pulls for single shots |
| Damage | TBD |
| Effective range | Real-world 100 m with slugs; in-game TBD |

## Real-world notes

5.2 kg; 18 in barrel; fires from an open bolt; recoil system leaves about 10% of normal 12-gauge recoil; reportedly fires after being submerged; built to need little cleaning; rail available for optics

## In-game traits

A true monster of a crate weapon; one roster entry that rolls one of 2 versions (see [Versions](#versions) below)
