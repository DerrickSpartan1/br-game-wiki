## Real-world notes

3.63 kg; 10.6 in barrel; built-in compensator in the barrel jacket, which adds muzzle flash and noise; chrome-lined bore; drums were matched to each gun by serial number and misfeed above about 65 rounds; open bolt, so it can fire if dropped; Germans used captured ones with 7.63mm Mauser ammo, so it shares ammo with the C96 in-game

## In-game traits

One roster entry that rolls one of 4 versions (see [Versions](#versions) below)

## Attachments

Pistol/SMG family attachments. Mag tiers (best guess, review later): 35 standard; 40 makeshift extended and quick; 50 extended quick; the real 71-round drum as extended

## Versions

4 versions after merging. Licensed copies and lookalikes become skins: China's Type 50, North Korea's Type 49 (different stock), Hungary's 48M, Poland's wz.41, Romania's Md. 1952, Iran's copy with a tangent rear sight, and Croatia's 1990s Šokac (folding stock, square receiver). Germany's MP 717(r) was the unconverted gun fed 7.63mm Mauser ammo, so it isn't a separate version.
