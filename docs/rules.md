# Rules

Decisions that apply to every gun. Each gun page follows these unless it says otherwise.

## Spawned version is fixed

Like PUBG, whatever version spawns is the gun you have for the match. Only attachments change it. There are no mid-match conversion kits, so the [Stoner 63](weapons/assault-rifles/stoner-63.md) can't swap between rifle and machine gun setups, the [KRISS Vector](weapons/smgs/kriss-vector.md) can't swap calibers, and [Janz revolvers](weapons/pistols/janz.md) can't swap cylinders.

## Fixed triggers

Guns that had swappable trigger packs in real life (HK's [MP5](weapons/smgs/mp5.md), [UMP](weapons/smgs/ump.md), and [HK33](weapons/assault-rifles/hk33.md) families) don't merge every fire mode into one gun. Each version gets one fixed trigger, mostly the standard semi/auto, with burst mixed into a few. Guns whose real selector already includes burst (M16A2, M4, KRISS Vector, Micro Galil, FAMAS, SG 550) keep it.

The [Steyr AUG](weapons/assault-rifles/steyr-aug.md)'s real progressive trigger (half pull for semi, full pull for auto) plays as a normal semi/auto switch on the fire-mode selector key.

## No jamming

Guns never jam or malfunction in-game. Real reliability problems (like the L85A1's or the early M16's) are flavor text only.

## No overheating

Sustained fire never costs accuracy. The G36's real overheating problem is flavor text only.

## Random recoil

No fixed, learnable spray patterns. Each gun's recoil is randomized so it's felt rather than memorized.

The randomness sits inside each gun's own personality: every gun has tendencies (how hard it climbs, how far it drifts sideways, how fast it settles), but the exact path is random every time. Real details like the AK-74's muzzle brake, the AK-107's balanced action, or the AN-94's tight first two shots shape those tendencies.

## Open-bolt delay

Open-bolt guns have a slight delay between the trigger pull and the shot. New guns get tagged as they're added; each gun page notes it under Fire mode / rate.

**Has the delay:**

- [AA-12](weapons/crate/aa-12.md)
- [MP 18](weapons/smgs/mp18.md)
- [Thompson](weapons/smgs/thompson.md)
- [MP 40](weapons/smgs/mp40.md)
- [PPSh-41](weapons/smgs/ppsh-41.md)
- [Sten](weapons/smgs/sten.md), including the Sputter Gun
- [M3 "Grease Gun"](weapons/smgs/m3-grease-gun.md)
- [Owen](weapons/smgs/owen.md)
- [Uzi](weapons/smgs/uzi.md): the full-size and Mini Uzi
- [MAC-10 and MAC-11](weapons/smgs/mac-10-11.md)
- [Sterling](weapons/smgs/sterling.md)
- [StG 44](weapons/assault-rifles/stg-44.md): the MKb 42(H) version only
- [Stoner 63](weapons/assault-rifles/stoner-63.md): the Automatic Rifle (and its belt-fed configurations later)
- [M16 / M4](weapons/assault-rifles/m16-m4.md): the M231 FPW funny version only

**Never has it:** closed-bolt guns like the Škorpion, MP5, P90, MP7, UMP, KRISS Vector, and PP-19 Bizon. Closed-bolt versions of the guns above don't have it either: the Micro Uzi, Uzi Pro, Uzi carbine, MAC pistol, Sterling Mk 6 and PAWS ZX-7, the Stoner 63 rifle and carbine, and semi-auto replicas.

## 3rd slot

Any gun typically carried in a pistol holster goes in the pistol / 3rd slot. That includes sawed-offs, other odd pistol-likes, stockless pistol versions of SMGs and rifles, and machine pistols that come from a main pistol, like the C96 Schnellfeuer and the Glock 18.

## Versions

- **One entry, many versions:** a gun with several versions is one roster entry. The randomizer picks the gun, then rolls one version for that match.
- **Rarity:** follows how many of each version were actually made.
- **Fire modes stay real:** a version keeps the fire modes it really had. Semi-auto-only versions, such as civilian models, stay in the pool for every gun, even if most of that gun's versions are full auto. Rolling one is part of the luck of the draw.
- **Merging:** versions that fire the same round and differ only in small details are merged into one, with the differences noted.
- **Family sharing:** versions share the gun's mastery track and cosmetics. A modernized model on the same action and mags (like the Galil ACE or the AK-103) stays in its family. A different maker's gun on the same layout is its own family, like the [HK416](weapons/assault-rifles/hk416.md) next to the [M16 / M4](weapons/assault-rifles/m16-m4.md). So is a ground-up redesign, even from the same maker and on the same mags, like the [AK-12](weapons/assault-rifles/ak-12.md) next to the [AK-74](weapons/assault-rifles/ak-74.md).
