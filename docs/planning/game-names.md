# Game names

The names the game uses in place of real ones ([Legal review](legal-review.md)). The wiki keeps real names on every page; this page maps them to game names. The owner approved the names here; vehicle names come when vehicles are added. Every invented name still gets a trademark search before release.

## Rules

- **Gun makers:** one made-up maker for each real maker or arsenal, with the same country and era feel ([Gun makers](#gun-makers)).
- **No sound-alikes:** a game name never sounds like the real brand, so no "Kolt" or "Glok." Trademark law looks at whether people could confuse the two, and parody names like Tarkov's carry that risk too.
- **Pistol versions** of a family share its maker, so the MP5 pistol comes from the same maker as the MP5.
- **Designations:** a mix of real and new ([Designations](#designations)).
- **Attachments:** plain descriptions: vertical foregrip, angled grip, red dot, holographic sight, 2x scope, 4x scope. A unique scope is named for what it does, like a 4x scope with range markings for the SVD's PSO-1.
- **Armor:** our own names for carriers, vests, plates, rigs, and helmets ([Armor](#armor)).
- **Gun cards show the version's name only** (owner, 2026-11-22), like Zavod-7 AV-47M. Families don't get game names.
- **Vehicles:** made-up makes and models, like guns, named when vehicles are added.
- **Ammo:** called by its caliber only, with no name attached, so 7.62×25mm Tokarev is 7.62×25mm ([Cartridges](#cartridges)).
- **Other games' terms:** our own names ([Other games' terms](#other-games-terms)).
- **Into the game:** once names are approved, the lead's tools read them from this page, so the gun, armor, and loot tables the game already reads don't change.

## Designations

Approved by the owner: a mix of real and new.

- **Each game maker has its own letters,** used as a prefix on its guns.
- **Military designations and years keep their number:** the letters change but the number stays, so the gun still reads right to people who know it.
- **Brand-style product names get a new name** in the maker's style, since the name itself is the product's trademark.
- **Version suffixes stay** (A1, A2, K, SD, C), so versions still read right.

| Real | Game (proposal) | Why |
| --- | --- | --- |
| Colt M16A4 | Harlan HR-16A4 | Military designation: the number stays |
| Kalashnikov AKM | Zavod-7 AV-47M | Military designation: the number stays |
| Glock 18C | Pichler PK-18C | Product name: real number, new letters |
| Uzi | Arava Kestrel | Product name: new name |

Each maker's naming habit is in the [Gun makers](#gun-makers) table.
