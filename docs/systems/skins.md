# Skins and mastery

Skins are modular and grounded.

- **Modular:** the main gun, the silencer, and other parts each take their own skin.
- **Grounded:** skins should feel realistic; nothing super crazy.

## Wardrobe

Players set skins in a wardrobe menu, one skin per gun per part. In a match, items take on those skins as they're picked up and put on a gun.

- Each gun has its own part skins, so an FN SCAR 5.56 and an M4 5.56 are skinned separately.
- An attachment uses the skin set for the gun it's mounted on. A silencer moved from the SCAR to the M4 switches to the M4's silencer skin.

The same wardrobe setup covers gear: armor, helmets, backpacks, and similar items each get their own skins.

The player character has its own wardrobe slots too, and more can be added over time:

- Hats, shirts, pants, socks, and shoes
- Maybe knee and elbow pads

Clothes never drop as loot during a match; outfits are set in the wardrobe only.

## Weapon mastery

Each gun family levels up through challenges, such as specific kills, unlocking cosmetics. Progress counts toward the whole family, so any version works; every C96 version counts toward C96 mastery, for example.
