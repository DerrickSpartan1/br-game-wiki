# br-game-wiki

Design wiki for a PC battle royale that brings back the feel of original 2018 PUBG, with a gun and ammo pool that changes every match.

**Read it:** https://derrickspartan1.github.io/br-game-wiki/

Pages are Markdown files in [`docs/`](docs/), so they also read fine right here on GitHub. The site is built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) and publishes automatically on every push to `main`.

To preview locally:

```sh
pip install -r requirements.txt
mkdocs serve
```
