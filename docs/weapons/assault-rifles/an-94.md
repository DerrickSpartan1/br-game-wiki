# AN-94 "Abakan"

| Spec | Detail |
| --- | --- |
| Category | Assault rifle |
| Cartridge | 5.45×39mm |
| History | Russia; designed 1980–1994 by Gennadiy Nikonov as the AK-74's replacement; made by Izhmash 1994–2006; too complex and expensive to replace the AK-74, so only limited special-purpose use (Chechnya, Dagestan, Crimea 2014); only about 2,000–2,500 made, called the world's rarest production rifle |
| Magazine (rounds) | 30- and 45-round AK-74 mags, 60-round casket; the magazine sits canted to the right (its most recognizable feature) |
| Fire mode / rate | Semi, 2-round "hyperburst" at about 1,800 RPM, and auto (the first two rounds go at 1,800, then it slows to about 600 RPM); a pulley system fires the second round before the recoil reaches you, so both rounds land almost in the same spot; closed bolt, so no open-bolt delay |
| Damage | TBD |
| Effective range | Real-world 800 m; in-game TBD |

## Real-world notes

3.85 kg; 15.9 in barrel; delays felt recoil for the first two shots, which raises hit chance; extremely complex inside

## In-game traits

Single version; very rare roll (crate-only vs. rare world spawn: TBD)

## Attachments

AR/LMG/battle rifle family attachments; adapter scope mount. Mag tiers: shares the AK-74's real mags (30 standard, 45-round RPK-74, 60-round casket); rest best guess, review later

## Versions

Single version: no other production variants. It shares 5.45×39mm and AK-74 magazines with the AK-74 family.
